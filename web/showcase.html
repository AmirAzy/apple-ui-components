Web components for cross-platform apps

Four components, one token file, no dependencies: a five-state dynamic island, liquid-glass surfaces, the iOS 27 controls and a macOS 11 window. The same numbers drive the Flutter widgets in flutter/apple_ui_kit, so a web prototype and a native build stay in step.

0 dependencies transform + opacity only RTL-safe reduced-motion aware web + flutter

Serve this folder over HTTP (python3 -m http.server 8000) — the island module is an ES module.

Dynamic island

5 states .island · island.js

One black pill that morphs between idle, compact, expanded, notification and call. Only the pill animates width and height; its five layers cross-fade with opacity and scale. Click it, or drive it from the buttons.

iOS 27 controls

switch · segmented · rows .sw · .seg · .glass-row

The switch is 51×31 with a 27 point thumb; the segmented control slides a white thumb under the selection. Both are plain DOM with ARIA, no framework, and they mirror IosSwitch and IosSegmentedControl in the Flutter kit.

macOS window

big sur .macwin · .macbar · .macsidebar

Title bar 38, traffic lights 12 with an 8 px gap, 10 px window radius, a 150 px sidebar and 28 px rows. The whole surface is LTR even on an RTL page, because that is what the window actually does.
